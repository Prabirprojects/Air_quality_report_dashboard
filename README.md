# 🇮🇳 Air Quality Report Dashboard

An interactive **Power BI dashboard** for analyzing air quality across India at the **state and city level**. The dashboard provides a visual overview of air-quality indicators, city-level comparisons, geographical distribution, and AQI trends over time.

## 📊 Dashboard Overview

The dashboard was created to explore air-quality patterns across different cities and regions of India and to make pollution-related data easier to understand through interactive visualizations.

### Key Features

- 📍 **City-wise Air Quality Analysis**
- 🗺️ **Geographical / Area-wise AQI Overview**
- 📈 **AQI Trend Analysis over the years**
- 🏙️ **Comparison of cities based on average AQI**
- 🌫️ **Average PM2.5 analysis**
- 💨 **Average CO analysis**
- 🧪 **Average SO2 analysis**
- 🧪 **Average NO analysis**
- 🔎 **Interactive city filter**
- 📊 Visual comparison of highly and comparatively less polluted cities

## 📌 Key Dashboard Metrics

The dashboard currently provides:

| Metric | Description |
|--------|-------------|
| PM2.5 | Average concentration of PM2.5 |
| CO | Average Carbon Monoxide level |
| SO2 | Average Sulfur Dioxide level |
| NO | Average Nitric Oxide level |
| AQI | Average Air Quality Index |

## 📈 Visualizations

The dashboard contains several visualizations, including:

- **Top polluted cities** based on average AQI
- **City-wise AQI comparison**
- **AQI trend overview**
- **Area-wise AQI map**
- **Air-quality KPI cards**
- **Interactive city slicer/filter**

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Data Visualization**
- **Data Analysis**

## 🎯 Project Objectives

The main objectives of this project are:

1. Analyze air quality across different cities and regions of India.
2. Compare AQI levels between cities.
3. Understand changes in AQI over time.
4. Analyze major air-quality indicators such as PM2.5, CO, SO2, and NO.
5. Present complex air-quality data through an interactive dashboard.
6. Identify geographical and city-level differences in air quality.
